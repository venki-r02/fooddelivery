# # Dhee Quick Bites - Food Delivery Website

A Django-based food delivery web application that allows users to browse food items, add items to a cart, manage delivery addresses, and place orders online.

## Features

- User Registration and Login
- Browse Food Items
- Add Items to Cart
- Address Management
- Place Orders
- View Order History
- Responsive User Interface

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Installation

```bash
git clone https://github.com/venki-r02/fooddelivery.git
cd fooddelivery
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
